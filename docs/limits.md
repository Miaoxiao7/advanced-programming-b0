# 当前限制与未完成事项

本文件记录 B0 版本的真实限制。按课程要求，未完成部分如实保留，不做补写。

## 一 功能范围限制

1. **只监听回环地址**。默认绑定 `127.0.0.1`，其他机器无法访问。原因：本版本无鉴权，
   避免误暴露；如需局域网演示，用 `--host 0.0.0.0` 启动，但必须自行加访问控制。演示页
   与接口同源同端口，同样没有访问控制，因此不额外放开监听范围。
2. **无持久化**。所有计算在内存完成，进程退出后不保留任何结果。使用者需要留存时由
   调用方自行保存响应正文。
3. **无产品化前端**。仅提供 HTTP/JSON 接口与一个只读静态演示页（`b0_stats/demo.html`，
   经 `GET /` 或 `GET /demo` 返回）。演示页不做输入校验、不存历史、不绘图，数值与错误码
   全部来自服务端，故不改变接口契约。
4. **单进程同步处理，未做并发压力验证**。采用 `ThreadingHTTPServer`，但只验证过顺序
   请求；未测并发下的数值一致性与内存占用。
5. **不支持 CSV 或文件上传**，输入必须是 JSON 数组。
6. **无 TLS**。生产式部署需前置反向代理。

## 二 数值与统计口径限制

1. **分位数使用线性插值**（位置 = (n−1)×q）。与部分教材的"取整位置法"结果不同，
   例如 4 个样本时 q1=1.75 而非 1.0。跨工具对比时须先对齐口径。
2. **异常值判据固定为 1.5×IQR 栅栏**，对偏态分布或小样本（n<4）不敏感，不应据此
   直接剔除数据。
3. **输出保留 6 位小数**，仅用于阅读与核对，不应用于二次高精度计算；需要更高精度时
   应直接调用 `summarise` 的返回值（同为 6 位，需扩展 `DECIMALS`）。
4. **样本数上限 10000**，为控制内存与响应时间而设；超限返回 400 而非截断。
5. **方差给出两个口径**：`variance_sample` 与 `std_sample` 除以 `n−1`（无偏估计），
   `variance_population` 除以 `n`。二者不可混用做跨工具比较，引用时须注明分母。
6. **过零率依赖输入顺序**，是对"序列形态"的描述而非集合属性：同一组数值换序后结果会变
   （如 `[1,-1,2,-2]` 为 1.0，`[1,2,-1,-2]` 为 0.666667）。零计为非负，分母固定为 `n−1`，
   全同号时为 0。用于无序测量值时只能作形态参考，不应当作分布特征。
7. **`peak` 是绝对峰值** `max(|x|)`，与"时间轴上的峰值"不是同一概念；`peak_to_peak` 为
   `max−min`，对单个离群值极敏感——示例中 100 同时把峰峰值抬到 99，而 IQR 口径只把它
   标为 1 个异常值，两种视角需并列阅读。

## 三 测试与检查限制

1. 覆盖率 99%，未覆盖行为 `app.py:105`（模块入口调用行），属结构性不可达。
2. 1 MB 体积上限以 16 字节小上限等价复现，未真实发送 1 MB 请求体。
3. 未编写性能基准测试，响应时间随样本数增长的趋势仅有定性观察（10000 个样本在本地
   亚秒级完成，未记录精确数值）。

## 五 已知风险

- 若使用者传入超长数组（接近 10000）且字段类型混杂，错误信息只定位到第一个非法下标，
  不汇总全部问题，排查时需逐个修正。
- Windows 下服务端提前关闭连接时，客户端可能收到 `ConnectionAbortedError`；这是
  HTTP/1.0 短连接行为，不影响响应正文，测试中已按此处理。
